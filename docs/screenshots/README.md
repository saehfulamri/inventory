# Tangkapan Layar

Letakkan screenshot aplikasi di direktori ini agar dapat ditampilkan di README.

## Daftar yang Disarankan

| Nama file | Halaman |
| --- | --- |
| `dashboard.png` | Dashboard (ringkasan + chart) |
| `pos.png` | Penjualan / POS dengan keranjang terisi |
| `products.png` | Daftar produk + filter |
| `reports.png` | Salah satu halaman laporan |

## Panduan

- Format PNG atau WebP, lebar 1280–1600 px, ukuran < 500 KB per file.
- Gunakan data demo dari `DevelopmentSeeder` (jangan data pelanggan asli).
- Sembunyikan informasi sensitif (token, email pribadi, URL internal) sebelum
  mengambil gambar.
- Setelah file tersedia, tambahkan ke `README.md`:

```md
## Tangkapan Layar

![Dashboard](docs/screenshots/dashboard.png)
![POS](docs/screenshots/pos.png)
```

> Direktori ini hanya berisi aset dokumentasi; tidak ada kode yang bergantung
> padanya.
